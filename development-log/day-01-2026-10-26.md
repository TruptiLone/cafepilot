# CaféPilot — Development Log

## Day 1 — October 26, 2026

**Project:** CaféPilot — AI-Powered Café Operations Assistant  
**Hackathon:** Meta Global AI Developer Hackathon

### Objective

Establish the CaféPilot development environment, initialize the backend application, and verify connectivity with the Meta Model API.

### Problem being addressed

Independent café owners manage inventory, sales, staffing, suppliers, and upcoming events across multiple disconnected systems.

CaféPilot aims to provide an AI-powered operational control center that proactively identifies issues, recommends actions, and enables owners to make informed decisions from a unified dashboard.

### Technical decisions and rationale

| Decision | Rationale |
|---|---|
| Python + FastAPI | Lightweight backend for APIs, inventory calculations, forecasting, and AI integration |
| React/Next.js | Interactive web-based dashboard for café owners |
| Meta Model API | AI reasoning and multimodal capabilities for CaféPilot workflows |
| Virtual environment | Dependency isolation and reproducible local development |
| Environment variables | Keep API credentials separate from source code |
| Synthetic café data | Develop and test workflows before integrating real operational systems |
